## [0.1.0] - 2026-07-29

### Added

- Standards-first Next.js example site with static product and documentation routes.
- Typed site configuration, content records, metadata, JSON-LD, crawler policy, and canonical URL helpers.
- Generated `llms.txt`, full-context text, Markdown docs, site profile, Atom feed, robots file, and sitemap.
- Extensible AEO implementation-readiness audit with deterministic unit coverage.
- Vitest, Playwright, formatting, linting, strict TypeScript, production build, and CI quality gates.
